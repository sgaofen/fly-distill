Methodology — 2D scoring

Evidence (Gemini cosine): the phenotype description "{{ q.phenotype }}" is embedded by gemini-embedding-2 (3072-dim) and cosine-similarity-ranked against every gene's pre-built embedding. Each gene vector already contains its FlyBase summary + structured phenotype bullets + cross-species MGI/HPO phenotype context, so the semantic match captures fly biology + ortholog biology together.

Quality score: 0.30·log₁(n_bullets)/log₁(30) + 0.25·log₁(n_refs)/log₁(25) + 0.20·log₁(n_pubs)/log₁(500) + 0.10·I[has_HPO] + 0.10·I[has_MGI] + 0.05·I[has_disease] − 0.15·I[stub (n_bullets ≤ 3)].

Quadrant cutoffs: evidence ≥ 0.55 and quality ≥ 0.50. The two axes are reported separately — never collapsed into a single score — so a sparsely-annotated gene with a strong semantic hit (NOVEL LEAD) is visible alongside a well-studied gene with the same hit (STRONG). This preserves Long's "absence of evidence is not evidence of absence" principle.
